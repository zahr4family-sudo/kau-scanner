Paket KAU Scanner — GitHub-first deployment

1) Upload seluruh isi folder ini ke root repository GitHub.
2) Hubungkan repository tersebut ke Cloudflare Pages (bukan GitHub Pages biasa).
3) Build command kosong; build output directory: .
4) Pastikan folder functions/api ikut terunggah agar Pages Functions berjalan.
5) Pasang binding D1: DB -> kau-access.
6) Pasang secret ADMIN_PASSWORD dan ADMIN_SESSION_SECRET.
7) Baca DEPLOY-GITHUB.md sebelum deployment.

Kuota perangkat default sekarang 2 perangkat per akun.
Database yang telah ada jangan dihapus.

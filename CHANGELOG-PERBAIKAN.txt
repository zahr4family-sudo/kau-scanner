KAU OMR — CHANGELOG PERBAIKAN PAKET PWA
Versi paket: 3.1.0 (perbaikan deployment dan stabilitas)

1. GitHub Pages: manifest start_url/scope diubah menjadi relatif agar aplikasi berjalan pada repository project pages.
2. Cloudflare Pages: ditambahkan _headers untuk kebijakan header dasar dan cache file inti.
3. Service worker: base URL mengikuti scope instalasi; cache versi; navigasi network-first dengan fallback offline; cache library XLSX CDN.
4. Penyimpanan: localStorage dan IndexedDB kini dicoba secara terpisah; akses localStorage yang gagal tidak menghentikan pemulihan IndexedDB.
5. Kamera: validasi HTTPS/getUserMedia dan pembersihan stream ketika gagal.
6. Cetak: penantian aset gambar, jeda render sebelum print, dan cleanup fallback.
7. Mobile/PWA: metadata aplikasi mobile dan viewport safe-area diperbarui.

Batas pengujian:
- Sintaks JavaScript dan Service Worker diperiksa dengan Node.js.
- Manifest dan struktur paket diperiksa secara lokal.
- Pengujian kamera, printer fisik, PDF printer, instalasi TWA/APK, serta deployment GitHub/Cloudflare harus dilakukan pada browser/perangkat dan domain hosting sebenarnya.
- Library XLSX masih menggunakan CDN; cache offline baru terisi setelah pemuatan berhasil saat online.


8. Auth/RBAC Cloudflare Pages: ditambahkan skema D1 users, user_devices, otp_codes, verification_tokens, user_sessions, app_settings; OTP Gmail Brevo API; registrasi/login; kuota Non-PAI/PAI; device fingerprint; VIP/promotion; endpoint admin.
9. Admin dashboard: admin.html untuk mode promosi, daftar/pencarian pengguna, quota usage, VIP, reset device, edit kuota dan blokir/aktifkan.
10. Frontend: UI registrasi-verifikasi Gmail pada Data & Kunci, login user, akses kuota pada pembuatan sesi kelas/mapel, helper API.
11. Deploy: ditambahkan panduan Cloudflare Pages Functions, D1 binding, secrets Brevo dan admin.
12. Pengujian tambahan: sintaks endpoint Pages Functions, frontend helper dan script inline diperiksa dengan Node.js. Pengujian integrasi D1/Brevo masih harus dilakukan setelah secrets dan database diisi.


PERBAIKAN AUTH/RBAC - 26 NOVEMBER 2026
- Pengguna tanpa sesi login tidak lagi mendapat akses bebas saat membuat kelas/mapel baru.
- Pemeriksaan kuota dilakukan setiap kali sesi kelas/mapel baru dibuat.
- Profil nama guru, sekolah, dan NIP pada registrasi tidak lagi diminta dua kali; registrasi mengambil data dari Data Identitas Ujian.
- Setelah registrasi/login, profil akun diselaraskan kembali ke identitas guru/sekolah pada Data & Kunci.
- Default kuota mapel Guru Non-PAI disesuaikan menjadi 1 (default kelas tetap 1; perangkat 1).
- Respons login menyertakan profil akun agar identitas bisa dipulihkan saat login di perangkat lain.
